SALES PROFILE CUSTOMIZER & SETUP

어떤 직군의 영업이든 내 상황에 맞게 세팅하세요

직군 프리셋을 고르면 검색 키워드, 추천 채용 사이트, 2축(적합도×긴급도) 채점 기준, 아웃리치 문체가 자동으로 채워집니다. 필요한 부분만 고쳐 setup.json으로 저장하세요.

이 페이지가 하는 것
직군 프리셋 적용 · 노코드 채점/문체 커스텀 · 비밀 없는 setup.json 생성
내가 직접 하는 것
로그인 · 봇 토큰/API 키 비공개 입력 · 초안 검토 후 직접 발송 (자동 발송 없음)
비밀값은 입력하지 마세요API 키, 봇 토큰, 서버 비밀번호, SSH 개인키 내용, OAuth 코드는 절대 여기에 넣지 않습니다.

내 영업 직군 · 업종 프리셋 선택

카드를 누르면 아래 입력값이 해당 직군에 맞게 자동 채워집니다. 이후 모든 항목을 자유롭게 수정할 수 있습니다.

브로셔·홈페이지 글 / 내 발신메일 붙여넣기 → 자동 세팅 (오프라인 분석)

브라우저 안에서만 분석하며 외부로 전송하지 않습니다. 파일(.pptx/.docx/.pdf), URL, 로컬 발신함(.mbox/.eml/IMAP)은 아래 CLI 명령으로 바로 처리할 수 있습니다.

# 브로셔 파일(.pptx/.docx/.pdf/.png/.jpg) + 자사/경쟁사 URL 자동 분석 (Crawl4AI 무료 JS 렌더링 지원):
python3 outbound.py profile bootstrap --company-url https://company.example.com --competitor-url https://competitor.example.com --brochure ./brochure.pptx --output setup.json --insights ./Targeting-Insights.md --sync --force

# 내 PC 발신메일함(.mbox/.eml/Thunderbird/Apple Mail) 구조·문체 분석:
python3 outbound.py profile style --discover
python3 outbound.py profile style --mbox ~/Downloads/Sent.mbox --config setup.json --apply

예약 실행 & 메신저 봇 · 선택

이 키트는 OMH·OmniRoute에 의존하지 않고 순정 Hermes에서 독립적으로 동작합니다.

선택 효율화: TypeSafe AI Jev (고속 사전 필터링 · 채점 · 초안 검수)

키가 없어도 로컬 규칙 채점으로 100% 동작합니다. 키를 쓰실 때만 이 옵션을 켜고, 실제 TYPESAFE_API_KEY(또는 JEV_API_KEY)는 나중에 로컬 터미널 $HERMES_HOME/.env에만 넣으세요.

추가 외부 서비스 (Firecrawl / Jev / Webshare / Groq / Apify / Composio) · 선택

모든 외부 API 키는 이 브라우저에 입력하지 않고, 나중에 로컬 터미널에서 $HERMES_HOME/.env에만 저장합니다.

설정 요약 확인

입력한 영업 프로필, 크롤링 보드, 채점 컷오프를 한눈에 확인합니다.

커스텀 설정 파일(setup.json)을 저장합니다

비밀값 없이 영업 프로필·크롤링·채점 설정만 저장됩니다. 저장 후 python3 outbound.py profile sync 또는 python3 outbound.py setup으로 바로 반영할 수 있습니다.

1) 프로필 즉시 반영 & 미리보기: python3 outbound.py profile sync --config setup.json --force && python3 outbound.py profile preview --config setup.json
2) 전체 설치/실행: python3 outbound.py setup --config setup.json --offline --no-launch
3) 첫 시나리오 실행: python3 outbound.py run --config setup.json --home ~/.hermes-outbound --output ./output --vault ~/Documents/Hermes-GTM
